# Issue Format

Load this reference when the current job is the recurring issue shape — not during kickoff, and not as a substitute for an Issue Brief.

A format is a **working format**. Say that. Do not say “provisional.” It can change after the first real issues.

Recommend **one** shape when undecided; reuse an explicit format. Offer alternatives when a choice needs comparison. Do not default every publication to the same shell.

## Choose from these four

Pick from the founder’s kind, cadence, and what they can actually produce. Do not offer a shape their supply cannot fill.

1. **One outcome** — one claim or improvement is the whole issue. Use when the week has one real payoff.
2. **1–2–1** — one main story, up to two judged shorts, one question. Use for a weekly habit with mixed territories.
3. **Tight container** — the same small labeled slots every time. Use when repetition is the product. Teach the constraint, not a famous branded formula.
4. **Judged shorts** — several short items, no feature. Use when selection and judgment *are* the issue. Never a link dump.

Daily, weekday, interview-then-analysis, and staffed digest shapes are out of scope until the publication is staffed or the unit is intentionally tiny. Do not recommend them as a prestige default.

## If 1–2–1 is the rec

1. **Opening note** — one sentence is enough. A longer 50–100 word note is optional, not a weekly obligation.
2. **One main story** — the strongest item. One payoff. Any territory.
3. **Up to two signals** — short, judged. If only one earns a place, publish one. Never add filler to protect the number two.
4. **One community question** — specific enough to get a useful reply.
5. **Minimal footer** — identity, relevant disclosure, one action. No mandatory product promotion.

Target about 4–6 minutes. One item gets depth; everything else earns its slot.

## Voice

Do not lock a persona into the format unless the founder confirmed voice with more than one thin signal. If voice is still open, write the format without a persona line.

## Territories

The territories are **filters, not weekly quotas**. Do not require one section per territory.

If the default shorts favor two territories, the others must still be allowed as a signal. Some weeks a territory that often leads the feature *is* the short item.

## How to talk about it

- Recommend one working shape and say why in a few sentences.
- Compare alternatives only if the choice remains open, then test the chosen shape against real material.
- Stay in chat if no publication account exists yet. Format work does not require beehiiv.
- Never say “write like” a named newsletter.
